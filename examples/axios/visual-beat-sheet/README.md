# Visual beat sheet — designer handoff

Open **VISUAL-BEAT-SHEET.html** in a browser for lesson navigation, search, chapter filters, and a narration visibility toggle. It is self-contained and uses no external assets or network requests. Keep the companion files beside it for its download links.

The complete sheet covers **25 lessons, 150 major-idea beats, and 443 narration sentences**. Each major beat defines the concept, visual metaphor/mechanism, graphics, sentence-level animation behavior, connection to the next idea, predicted silent inference, and comprehension risk. Every lesson also has a persistent environment, spatial blocking, camera direction, and information hierarchy.

- **VISUAL-BEAT-SHEET.md:** complete editable planning document, including exact narration and matched visual actions.
- **beat-sheet.json:** structured beat and sentence data for production.
- **GRAPHICS-INVENTORY.md:** required graphics grouped by lesson and beat.
- **REVIEW-WORKSHEET.md:** silent-viewing questions, observation template, and key misconceptions to test.
- **COVERAGE-CHECK.json:** actual coverage checks and explicit untested areas.

No new video or animatic has been produced. The existing audio supplies beat windows; sentence windows are estimates based on word share. They must be aligned and adjusted during animatic work. Silent comprehension, pacing, and factual freshness have not been validated by this planning exercise.

The HTML's structure, internal links, download targets, and JavaScript syntax were checked. Browser policy blocked the local-file preview, so interactive browser behavior and visual layout were not verified in this session. The Markdown provides the same complete beat content without relying on those controls.

Start creative review with the full sheet. The proposed next production step is a rough animatic of lessons **07, 08, and 11**, followed by actual silent-viewer testing before scaling to the remaining lessons. This handoff proposes that sequence; it has not started it.
