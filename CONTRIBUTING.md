# Contributing

Continuous-Learning-Video is maintained by [TahaDali](https://github.com/TahaDali). Start with a sanitized issue describing the user problem and a small reproducible example. The maintainer decides which changes enter the official project.

Keep one skill entry point and preserve the research-to-delivery contract. Do not add provider integrations, broad refactors or new dependencies without explaining their need. Do not submit private job documents, course URLs, personal data, credentials or copied material without redistribution rights. Use fictional fixtures.

Install the locked rendering dependency and run the four checks in the README. Add focused regressions for demonstrated failures. Explain what was checked and what remains unverified; do not turn schema/media passes into claims of factual, listening or learning quality.

Update `skill-files.json` deliberately when runtime resources change. Build and scan a new bundle outside the source tree. Keep generated media, dependencies, caches and local review evidence out of commits. Review changes to executable scripts, Actions, dependency locks, licensing and notices carefully.

Submit a pull request with the problem, resulting behavior, tests and any compatibility or rights considerations. Contributions are offered under the project's Apache-2.0 terms; preserve existing applicable notices and identify external material. No copyright assignment is requested. Security reports belong in the private route in SECURITY.md.
