# Axios job-to-private-course trial

Tested October 20, 2026, with the assembled `job-to-learning-videos` skill and [Axios Staff Software Engineer posting 8229298](https://job-boards.greenhouse.io/axios/jobs/8229298). This is an agent-driven authoring trial, not an unattended URL-to-video compiler benchmark. Existing local rendering and speech dependencies were reused; no installed personal skill was overwritten.

## First trial retained as historical evidence

The complete workflow reached a confirmed owner-private hosted course: 18 lessons across six sections, 4,176 narration words, 90 spoken blocks, 310 sentence cues and 1,835.16 seconds of measured media (30:35). Thirty-two posting requirements map to 18 learning objectives. The story moves from the organization and publishing economics through engineering boundaries, AI verification, operational leadership, candidate evidence and illustrative advancement. Dispatch, its people, system and work are explicitly fictional teaching examples. Public employer facts and engineering principles have linked sources.

Actual narration used the selected Microsoft Ava voice through a compatible `edge-tts` 7.3.1 interface. A transient bulk request failure preserved completed blocks; the run resumed at concurrency two using the same provider. Final videos use H.264/AAC at 1280 × 720 and 24 fps, with downloadable captions and in-player transcripts.

The deployment used the exact pushed Site source and matching packaged archive. Native Sites confirmed success. The post-deployment access response showed one allowed owner, zero allowed groups and zero external visitors. The GitHub repository and PR remain private and draft, respectively. Neither audience was expanded.

## Fixes carried into the reusable skill

- Regenerate readable beat sheets from canonical JSON after visual and narration recording; legitimate measured timing updates no longer invalidate the upstream visual plan.
- Wrap labels using measured font widths and safe line spacing, expose returned text height, and document inspection of internal shape boundaries.
- Archive prior flagged screenshots with their old report before creating a fresh audit result.
- Expose bounded speech concurrency and identify the failed block after bounded retries while retaining the cache.
- Preview the exact allowlisted export through a directory option on the loopback server.
- Group lessons by section, display readable source dates and review labels, and announce playback errors accessibly.

## Review still required

Full perceptual listening was unavailable: the review environment cannot hear audio. Complete synchronized watching/listening and complete silent viewing were not performed. Mobile-device playback, fullscreen legibility, a complete accessibility audit, and learner comprehension testing remain pending. The hosted page visibly states these review limits and is not represented as publicly ready.

The private working project retains source snapshots, evidence mapping, manuscript, editable production source, measured audio/timing, final media, encoded frame samples, silent excerpts, a complete listening file, acceptance record, export manifest and delivery record. Those generated materials, account identifiers and the private Site URL are intentionally absent from this reusable repository.
